### 📦 Prerequisites
Make sure you have the following installed:

- **Node.js** (v24 recommended)
- **npm**
- Git

---

## 🔧 Backend Setup (API Server)
cd backend
npm install
npm run build
npm run dev

http://localhost:4000


## 🔧 FrontEnd Setup (UI Server)
cd time-slot-manager
npm install
npm run dev

http://localhost:3000
